# Q3 Booster Up — Monitoring Dashboard

Dashboard khusus untuk memantau program berjalan **Q3 Booster Up (Periode 1 Okt – 31 Des 2026)** secara mandiri, terpisah dari dashboard utama FY26.

- **GitHub Pages (Online)**: `https://ariswidodo.github.io/Q3-Booster-Up/`
- **Server Lokal Mandiri**: `http://127.0.0.1:8766/` (klik ganda `start_dashboard.bat` atau shortcut Desktop **Q3 Booster Up**).

## Cakupan Aturan
- **Sumber Pembelian**: 4 EPP Lokal (`PT Computek`, `Raka Perkasa`, `Computa`, `Top Distribusi`).
- **Peserta & AE/AM (`data/peserta_booster.csv`)**: 82 EPR (`ARIS` 20, `HERDIAN` 42, `SIGIT` 20 — 75 Consumer & 7 Consumables).
- **Filter SKU Tinta (`data/booster_consumables_sku.csv`)**: 31 SKU resmi (`8` `INK BOTTLE` / `664/003` + `23` `OTHERS INK BOTTLE` / `Lainnya`).
- **Update Mandiri**: tab **Upload Sell Out** & **Update Master** di dalam tombol **Upload Data** (saat berjalan di server lokal).
